# Cathy’s Cakes Website

## 1. Project Overview

Cathy’s Cakes is a bakery website developed to showcase cakes, cupcakes and cake pops. The website allows customers to explore available products, learn more about the business, register for an account, log in and submit cake order enquiries.

The bakery was established in 2021 and is located in Wonderpark Estate, Karen Park, Pretoria.

The purpose of this website is to improve the online presence of Cathy’s Cakes and provide customers with a convenient way to explore products and enquire about orders.

## 2. Technologies Used

The following technologies were used to develop the website:

* **HTML5:** Used to create the structure and content of the website.
* **CSS3:** Used to style the website, including layouts, colours, buttons, forms and navigation.
* **JavaScript:** Used to implement interactive features such as registration, login, order submissions, product searching and image viewing.
* **Local Storage:** Used to store customer registration information and submitted order enquiries in the browser.
* **Session Storage:** Used to maintain the customer's login session.

## 4. Improvements and Fixes Implemented

The following improvements were made to enhance the website's functionality, appearance, usability and search engine optimisation.

### 4.1 Search Engine Optimisation (SEO)

* Added meta descriptions to help search engines understand the content of individual website pages.
* Improved page titles to make each page easier to identify.
* Used descriptive meta description wording relevant to Cathy’s Cakes, its products and location.
* Improved image alternative text recommendations to make images more accessible and understandable to search engines.

### 4.2 Image Names and Alternative Text

* Improved image descriptions by using meaningful alternative text.
* Added descriptive examples of image names to support better organisation and SEO.
* Ensured that image alternative text describes the actual cake or product displayed.
* Improved accessibility for visitors who use screen readers.

### 4.3 Registration Functionality

* Implemented customer registration using JavaScript.
* Added validation to ensure that all required registration fields are completed.
* Added email format validation.
* Added password length validation requiring at least eight characters.
* Added password confirmation to ensure both password entries match.
* Prevented customers from registering with an email address that is already in use.
* Stored registered customer information using browser local storage.

### 4.4 Login Functionality

* Implemented a customer login system.
* Added email and password verification.
* Displayed an error message when incorrect login details are entered.
* Used session storage to maintain the customer's login session.
* Added automatic redirection after successful login.
* Added a welcome message for logged-in customers.

### 4.5 Order Page Protection

* Restricted access to the order page for customers who are not logged in.
* Redirected customers to the login page when they attempted to access the order page without an active session.
* Redirected customers back to the order page after successfully logging in when they originally requested access to it.

### 4.6 Order Enquiry Form Functionality

Improved the order form to make it more user-friendly and functional.

The form includes:

* Cake type selection.
* Quantity selection.
* Flavour selection.
* Collection date.
* Cake theme.
* Additional requirements.
* Customer contact number.

Additional improvements include:

* Added required field validation.
* Restricted the quantity to a minimum of 1 and maximum of 500.
* Prevented customers from selecting collection dates in the past.
* Added validation for South African 10-digit phone numbers.
* Saved submitted order enquiries in browser local storage.
* Added a confirmation message after successful submission.
* Reset the form after an enquiry has been submitted.
